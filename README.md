# Blockout

**Blockout** is a Minecraft **Fabric mod** (Java) for **Minecraft 1.21+** that brings fast-paced, competitive challenge game modes to play with friends.

It focuses on **Lockout-style gameplay**, randomized objectives, and fun modifiers that turn every match into controlled chaos.

---

## What is Blockout?

Blockout is a mod designed to play **Minecraft Lockout** and other competitive mini-game modes inside a normal Minecraft world.

Each game generates a set of randomized goals, and players or teams race to complete them before their opponents.

Everything is configurable through a **custom in-game GUI**, so setting up a game takes seconds.

---

## Main Game Mode: Lockout

Over **300 possible goals** can appear in a match.

### Game Setup Options

- Choose number of goals:
  - 9
  - 25
  - 49
  - 81
- Set difficulty
- Play solo or in teams
- Remove goal categories:
  - No End goals
  - No Nether goals
  - No food goals
  - (and more)

### Gameplay Features

- Randomly generated goal board every game
- Team play or solo practice
- Death behavior options:
  - Normal respawn
  - Respawn at a teammate
- Player tracking compass:
  - Track all players in real time
- Automatic brightness boost:
  - Brightness is set to 400%

---

## Modifiers (Optional Chaos)

You can enable gameplay modifiers to make matches more unpredictable:

- Touching water gives poison
- You can swim in lava but receive blindness
- More modifiers planned

---

## Other Game Modes

### Block Swap

Block types in the world are swapped.  
You receive an objective to find a specific block faster than your opponents.

### Block Drop Randomizer

All block drops are fully randomized.  
Players must obtain a specific target block first to win.

---

## Mechanics Tweaks

- Uses **1.16-style bartering**
- Some goals modify drop tables to prevent objectives from taking too long
- Designed to keep games fast, competitive, and fun
